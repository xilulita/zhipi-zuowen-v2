# 智批作文 · AI 作文批改工作台

面向小学高年级到初中的作文批改工具：**四维评分雷达、双侧逐句批注、写作思路、小练笔、升格范文，以及所见即所得的白板导出**。

纯前端单页应用，无后端、无数据库，作文与批改结果只存在本机；同时提供 Electron 桌面版（NSIS 安装向导，可自选安装目录）。

> 这是重构后的模块化版本，与 [`xilulita/zhipi-zzz`](https://github.com/xilulita/zhipi-zzz) 是两条独立演进线，互不影响。

## 一、下载安装

到 [Releases](https://github.com/xilulita/zhipi-zuowen-v2/releases) 下载最新的 `智批作文-x.x.x-安装包.exe`：

也可以不安装，直接用浏览器打开仓库根目录的 `index.html` 使用。

## 二、使用流程

1. **左侧填学生姓名**（可选）→ 选**体裁**与**年级**（年级下拉悬停可看该年级写作要求与字数区间）
2. **上传作文照片**（支持多页，按顺序合成一份）或直接粘贴正文
3. 点**开始 AI 批改**
4. 右侧出报告：总分/等级、四维雷达图、整篇研判、写作思路、小练笔、润色稿
5. 可切 Tab 查看，也可一键**导出 HTML 白板**（版式与界面所见一致）

支持一次载入多份作文，各自独立保留原稿、参数与结果，可随时切换；结果同时写入历史记录，刷新不丢。

## 三、批改是怎么做的

### 3.1 视觉直读，不做本地 OCR

把作文照片直接交给多模态模型，模型返回 `box: {y, x1, x2}` 百分比坐标与页码，前端据此在**图片两侧留白**里画荧光条、编号和批注卡。多页作文一次送入多张图，按 `page` 字段各自归位。

### 3.2 两阶段调用

| 阶段 | 产出 |
|---|---|
| 阶段一 | 评分、四维明细、逐句批注、写作思路、小练笔（`polished` 留空） |
| 阶段二 | `ZP.polishEssay()` 生成升格范文 |

拆分的好处：报告能先出来，范文慢一点也不阻塞首屏。

### 3.3 速度与稳定性

- **关闭深度思考**：火山方舟 `thinking: {type: "disabled"}`，界面上的「优先速度 / 优先质量」开关对应这一项
- **温度可调**：滑块值持久化，并真实进入请求参数
- **JSON 容错**：`jsonComplete()` 用括号配平判断是否截断 → `continueIfTruncated()` 续写 → `ZP.parseJSON()` + `ZP.balanceJSON()` 兜底补齐
- `response_format` 不被支持时自动重试

详细的提示词结构、字段约束与坐标约定见 [`docs/AI批改逻辑技术文档.md`](docs/AI批改逻辑技术文档.md)，可移植到其他 AI 软件。

## 四、几个实现要点

**四维评分**：内容立意 30 / 结构逻辑 25 / 语言表达 25 / 规范书写 20（可在左侧量表调整），配色为同一色相的暖色阶梯，不混用语义色。

**批注排布**：`fixBoardLayout()` 先把 `transform` 清掉、量出真实高度，再自上而下推开，卡片按对应划线位置纵向排布，不靠估算高度做绝对定位。

**口径变更**：切题材或年级时**不清空结果**，只把报告标记为「需复核」，顶部出现提示条；切回原设置提示自动消失。

**耗时与用量**：左侧「本次批改」卡按阶段展示耗时/tokens 双条，超 60 秒换算成 `2m 14s`。

**导出**：单页流式、不分页；HTML 与界面共用同一套版式结构。

---

## 五、接口配置

界面内点「接口配置」填写，支持任意 OpenAI 兼容接口（内置 DeepSeek、通义千问、Kimi、智谱、OpenAI、火山方舟等预设）。

- 需要**支持看图的多模态模型**，纯文本模型只能批改粘贴的正文
- 密钥只保存在本机 `localStorage`，不经任何第三方服务器

## 六、目录结构

```
.
├── index.html              单页入口
├── assets/
│   ├── css/                base.css（变量/配色）· app.css（界面）
│   └── js/
│       ├── config.js       年级、体裁、四维权重、接口预设
│       ├── ai.js           请求封装、JSON 容错、提示词与两阶段流程
│       ├── render.js       白板、批注卡、雷达图、报告渲染
│       ├── report-export.js 白板 HTML 导出
│       ├── history.js      历史记录
│       ├── notice.js       消息中心
│       └── app.js          主流程与状态
├── main.js                 Electron 主进程
├── preload.js              最小预加载（只暴露版本号）
├── build/                  安装包图标
├── docs/                   技术文档、项目交接文档、创作日志
└── local_ocr/              可选的本地 OCR 辅助服务（默认不用）
```

## 七、本地开发

```bash
npm install
npm start          # Electron 调试
npm run dist:win   # 打 NSIS 安装包 → dist/
```

网页版调试用任意静态服务器打开根目录即可，例如 `python -m http.server`。

> 本机打包有系统盘空间与签名工具的额外约束（缓存目录、winCodeSign 符号链接、rcedit 临时空间），
> 完整命令与踩坑处理见 [项目交接文档 §5.2](docs/项目交接文档.md#52-桌面端打包本机特有约束)。
